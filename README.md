One joke pickup line aimed at a robot or an AI: a million
simulations of meeting you, and it still froze on the first line —
so this one is unrehearsed.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–200 characters, no trailing newline.
